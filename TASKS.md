## Tips
- Clone the repo, make small commits, pull before you push.
- Use clear messages (what changed and why). Avoid one giant commit.
- Everyone should also tweak something small in a teammate's file via a commit (e.g. fix a typo, add a product) to show collaboration.
- Video (10+ min, everyone on camera): intro, business process, demo, code walkthrough (`@when` events, DOM updates, localStorage), individual contributions.
